# Tibetan-Unicode-Keyboard
This is an Excel file that mimics a screen keyboard for the typing of Tibetan characters. A Tibetan character is formed by stacking the middle (core) character, then the lower character stack(s) and finally upper stack. This works well in Windows 10 and above, not in Macbook.
